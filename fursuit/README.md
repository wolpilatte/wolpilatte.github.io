# Foto Fursuit

Taruh foto fursuit di folder ini. Foto akan otomatis muncul di kartu layanan.
Nggak perlu edit HTML lagi.

## Nama file

Pakai `.png` atau `.jpg`. Kalau dua-duanya ada, file `.png` yang dipakai.

| Kartu | Nama file |
| --- | --- |
| Paws & Feetpaws | `paw.png` / `paw.jpg` |
| Custom Heads | `head.png` / `head.jpg` |
| Mini Partial | `mini-partial.png` / `mini-partial.jpg` |
| Full Partial | `full-partial.png` / `full-partial.jpg` |
| Tails & Accessories | `tail.png` / `tail.jpg` |
| Refurbish | `refurbish.png` / `refurbish.jpg` |

Contoh: simpan foto paws sebagai `fursuit/paw.jpg`.

## Tips

- Rasio paling pas 16:10. Foto lain tetap bisa, nanti di-crop otomatis.
- Nama file harus huruf kecil dan pakai tanda `-`, bukan spasi.
- Kalau file belum ada, kartu tetap memakai gradient dan ikon seperti sekarang.
  Gambar rusak nggak akan kelihatan.
- Foto untuk tombol **View Fursuit Examples** ada di folder utama, yaitu
  `f1.jpeg` sampai `f8.jpeg`. Ganti file itu kalau mau update contoh fursuit.

## Ukuran

Disarankan lebar 800 sampai 1200 px, supaya cepat dibuka tapi tetap tajam.
